# Python Basics
## Module 1: Values, variables and strings
### Variables and types
- `=` binds a name
- `type()` shows the type
- `str`, `int`, `float`, `bool`
### Converting between types
- Input arrives as `str`
- `int()`, `float()`, `str()`
- Mixing types raises `TypeError`
### f-strings
- `f"{value}"` inserts values
- `:.2f` for two decimals
### Working with strings
- Index from 0, `-1` is last
- `s[a:b]` stops before `b`
- `len()`, `.upper()`, `.replace()`
- Methods return new strings
## Module 2: Control flow and functions
### Decisions with if, elif and else
- First true branch runs
- `else` catches the rest
- Indent blocks four spaces
### Loops
- `for` once per item
- `while` until condition false
- `range(n)` excludes `n`
### Functions
- `def name(params):`
- Defaults make parameters optional
- `return` sends a value back
- No return gives `None`
