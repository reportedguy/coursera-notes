> This module lets you store values in variables, convert between types and build text with strings.

## What you'll be able to do
- Store values in variables and check their type.
- Convert text to numbers and back without errors.
- Build readable output with f-strings.
- Slice and transform strings.

## The big idea
Every value in Python has a **type**, and the type decides what you can do with it. You can add two numbers, but not a number and a piece of text. Most beginner errors are type errors, so knowing each value's type, and converting when needed, is the core skill of this module.

## Variables and types
**What and why:** A **variable** is a name that points to a value; `=` binds the name to it. Python works out the type from the value itself, so you never declare it. `type()` shows the type of any value.

```python
name = "Ada"
age = 36
print(name, age)
print(type(name), type(age), type(3.5), type(True))
```
Output:
```
Ada 36
<class 'str'> <class 'int'> <class 'float'> <class 'bool'>
```

| Type | Holds | Example |
|---|---|---|
| `str` | Text | `"Ada"` |
| `int` | Whole numbers | `36` |
| `float` | Decimal numbers | `3.5` |
| `bool` | `True` or `False` | `True` |

## Converting between types
**What and why:** Input from users and files arrives as text (`str`), even when it looks like a number. `int()`, `float()` and `str()` convert a value to a new type so it can take part in the operation you want.

```python
price = "19.99"
qty = "3"
print(float(price) * int(qty))
print(str(age) + " years")
```
Output:
```
59.97
36 years
```

**Watch out:** Adding text to a number fails with `TypeError: can only concatenate str (not "int") to str`. Fix it by converting one side: `str(3)` for text, `int("3")` for arithmetic.

## f-strings
**What and why:** An **f-string** is a string with an `f` before the quote. Anything inside `{}` is evaluated and inserted, so you can mix text and values without converting by hand. A format spec after `:` controls the display, such as `.2f` for two decimals.

```python
city = "Lisbon"
print(f"{name} lives in {city} and is {age}.")
print(f"Total: {float(price) * int(qty):.2f}")
```
Output:
```
Ada lives in Lisbon and is 36.
Total: 59.97
```

## Working with strings
**What and why:** A string is a sequence of characters, so you can index it, slice it and measure it. **Indexing** starts at 0, and negative indexes count from the end. A **slice** `[start:stop]` includes `start` but stops before `stop`. **Methods** like `.upper()` return a new string; the original never changes.

```python
word = "python"
print(word[0], word[-1], word[0:3], len(word))
print(word.upper(), word.replace("py", "PY"))
```
Output:
```
p n pyt 6
PYTHON PYthon
```

| Form | Does |
|---|---|
| `s[i]` | Character at position `i` (0 is first, -1 is last) |
| `s[a:b]` | Characters from `a` up to, not including, `b` |
| `len(s)` | Number of characters |
| `s.upper()` | Copy in capitals |
| `s.replace(old, new)` | Copy with every `old` replaced by `new` |

**Watch out:** `word.upper()` does not change `word`. Assign the result (`word = word.upper()`) if you want to keep it.

## Recap
- Every value has a type; `type()` shows it.
- Text from users and files is `str` until you convert it.
- `int()`, `float()` and `str()` convert; mixing `str` and numbers raises `TypeError`.
- f-strings insert values with `{}` and format them after `:`.
- Indexes start at 0; slices stop before the end index.
- String methods return new strings and leave the original unchanged.

## Glossary
| Term | Meaning |
|---|---|
| f-string | A string prefixed with `f` whose `{}` parts are evaluated. |
| Indexing | Getting one character by position, starting at 0. |
| Methods | Functions attached to a value, called with a dot. |
| Slice | A part of a string from a start up to an end. |
| Type | The kind of value, which decides what you can do with it. |
| Variable | A name that points to a value. |
