# Planning a Small Project
## Module 1: Defining the project
### Goals that can be checked
- 1. Specific
- 2. Measurable
- 3. Achievable
- 4. Relevant
- 5. Time-bound
### Scope: in and out
- Deliverables with a done line
- Out-of-scope list
- Change process for every request
- Scope creep: unplanned added work
### Stakeholders
- Rate influence and interest
- Power–interest grid
  - Manage closely
  - Keep satisfied
  - Keep informed
  - Monitor
- Sponsor makes final call
### The project charter
- Goal, scope, stakeholders
- Budget and key dates
- Risks and assumptions
- Sponsor sign-off
## Module 2: Scheduling and tracking
### Breaking down the work
- WBS from deliverables
- Tasks of a day to a week
- One owner per task
### Estimating with three points
- Optimistic, likely, pessimistic
- (O + 4M + P) ÷ 6
- Owners give the numbers
### Dependencies and the critical path
- Dependency blocks a start
- Longest chain sets finish date
- Float: slack off the path
### Tracking and status reports
- RAG: Red, Amber, Green
- Done and next week
- Risks with owners
- Decisions with deadlines
